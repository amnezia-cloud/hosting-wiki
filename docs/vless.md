# VLESS + Reality: подробное руководство

**VLESS** — современный протокол ядра **XRay**, а **Reality** — технология маскировки, которая делает VPN-трафик неотличимым от обычного посещения разрешённого сайта. Это самый устойчивый к блокировкам вариант в нашем стеке.

## Как работает Reality

Обычные способы маскировки под HTTPS используют самоподписанный сертификат, который DPI может «раскусить». Reality идёт дальше: при подключении сервер **на лету заимствует настоящий TLS-хендшейк** реального крупного сайта (например, `dl.google.com`). Для наблюдателя это выглядит как обычное безопасное соединение с легитимным ресурсом — отдельный сертификат и домен не нужны.

## Ключевые параметры

| Параметр | Назначение |
| :--- | :--- |
| `dest` / `SNI` | Реальный сайт, под который маскируется трафик (например, `dl.google.com:443`) |
| `flow` | Режим передачи, обычно `xtls-rprx-vision` |
| `publicKey` (`pbk`) | Публичный ключ сервера (x25519) для клиента |
| `shortId` (`sid`) | Короткий идентификатор сессии |
| `fingerprint` (`fp`) | Имитируемый браузер uTLS: `chrome`, `firefox` и т.д. |
| `spiderX` (`spx`) | Путь для дополнительной маскировки, обычно `/` |

## Формат ссылки подключения

Ключ доступа VLESS выглядит так — его можно импортировать в клиент по ссылке или QR-коду:

```text
vless://UUID@ВАШ_IP:ПОРТ?type=tcp&security=reality&sni=dl.google.com&fp=chrome&pbk=ПУБЛИЧНЫЙ_КЛЮЧ&sid=SHORT_ID&spx=%2F&flow=xtls-rprx-vision#Имя-подключения
```

## Установка

**Вариант 1. Через приложение AmneziaVPN (проще).** Добавьте сервер (см. **[Настройка VPN](/vpn-setup)**) и на вкладке протоколов нажмите **«Установить»** напротив **XRay**. Параметры Reality сгенерируются автоматически.

**Вариант 2. Через веб-панель 3X-UI (гибче).** Позволяет вручную создавать подключения и выдавать отдельные ключи разным пользователям. Пошаговая инструкция — в разделе **[Панель 3X-UI](/3x-ui)**.

## Клиентские приложения

Сгенерированные ссылки `vless://…` поддерживаются всеми современными клиентами:

| Платформа | Приложения |
| :--- | :--- |
| **Android** | Hiddify, v2rayNG, NekoBox |
| **iOS (iPhone)** | Streisand, FoXray, Shadowrocket, V2Box |
| **Windows / macOS** | Hiddify, NekoRay, v2rayN |

## Когда выбирать VLESS + Reality

*   <Icon name="check" tone="ok" /> Регионы с жёсткой цензурой, где блокируют VPN-протоколы и UDP.
*   <Icon name="check" tone="ok" /> Как надёжный **запасной** протокол, если **[AmneziaWG](/awg)** перестал подключаться.
*   <Icon name="warning" tone="warn" /> Чуть выше нагрузка на процессор и, как правило, немного ниже скорость, чем у AWG.

::: tip Совет по маскировке
В качестве `SNI`/`dest` выбирайте крупный сайт, который заведомо не заблокирован в вашем регионе и поддерживает TLS 1.3 — тогда маскировка максимально правдоподобна.
:::
