# Как сменить пароль root

## Если доступ к серверу есть {#passwd}

Подключитесь по SSH и выполните:

```bash
passwd
```

Система запросит новый пароль дважды. Символы при вводе не отображаются — это норма. Пароль меняется сразу, переподключение не требуется.

## Если пароль утерян {#reset}

Пароль перевыпускается кнопкой **Reset Password** в карточке сервера на **[my.amnezia.host](https://my.amnezia.host)**. Сервер предварительно нужно выключить командой **Shutdown**.

::: danger Проверьте дату выдачи сервера
`Reset Password` работает только на серверах, выданных **с 20 июля 2026 года**. На более старых VPS кнопка переводит сервер в состояние **Bad State**, и его придётся заменить через поддержку. Подробнее — **[Переустановка ОС](/reinstall#check)**.

Если ваш сервер выдан раньше этой даты и пароль утерян — не нажимайте кнопку, сразу создайте тикет.
:::

## Какой пароль куда {#which-password}

| Пароль | Где используется |
| :--- | :--- |
| **Пароль root (SSH)** | Подключение к серверу по SSH, добавление сервера в приложение AmneziaVPN |
| **Пароль личного кабинета** | Вход на my.amnezia.host, счета, действия с сервером |
| **Пароль панели 3X-UI** | Вход в веб-панель, восстанавливается на сервере командой `x-ui settings` |

::: warning Пароли не пересылаются
Поддержка никогда не запрашивает пароль root. Не вставляйте пароли в тикет или чат — если пароль уже был отправлен, смените его командой `passwd`.
:::
