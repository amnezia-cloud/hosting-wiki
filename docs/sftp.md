# Файловое хранилище SFTP

## Общая информация

Помимо создания и использования VPN, с помощью **AmneziaVPN** можно развернуть файловое хранилище на вашем виртуальном сервере. После установки к хранилищу можно подключиться через любой SFTP-клиент, например **FileZilla**, или [смонтировать хранилище как локальную папку](https://docs.amnezia.org/ru/documentation/instructions/sftp-mount-folder) на компьютере.

## Установка SFTP

1. На главном экране нажмите на название сервера.
2. Нажмите на иконку настроек рядом с названием сервера.
3. Перейдите на вкладку **Сервисы** и выберите **SFTP-сервис для обмена файлами**.
4. Оставьте порт `222` по умолчанию или укажите другой, затем нажмите **Установить**.

![Установка SFTP-сервиса: выбор сервера, сервиса и порта](/img/sftp/sftp1_ru.png)

## Просмотр данных для подключения

1. После установки снова перейдите на вкладку **Сервисы** и выберите **SFTP-сервис для обмена файлами**.
2. Выберите **SFTP-сервис настройки сервера**. Откроется экран **Настройки SFTP**.

На экране настроек будут показаны хост, порт, имя пользователя и пароль. Эти данные используются для подключения к файловому хранилищу через любой SFTP-клиент.

![Переход к настройкам SFTP и данным для подключения к хранилищу](/img/sftp/sftp2_ru.png)

## Подключение через FileZilla

1. Откройте сайт [FileZilla] и нажмите **Download FileZilla Client**.

   ![Кнопка Download FileZilla Client на главной странице FileZilla](/img/sftp/sftp3.png)

2. Скачайте **FileZilla Client** для вашей операционной системы.

   ![Страница загрузки FileZilla Client на примере Windows](/img/sftp/sftp4.png)

3. Если FileZilla откроет страницу выбора редакции, выберите бесплатную редакцию **FileZilla** и нажмите **Download**.

   ![Выбор бесплатной редакции FileZilla и кнопка Download](/img/sftp/sftp5.png)

4. Установите FileZilla.
5. Откройте FileZilla. В поле **Хост** укажите IP-адрес сервера с префиксом `sftp://`, например `sftp://199.10.20.171`.
6. Укажите имя пользователя, пароль и порт из настроек SFTP в **AmneziaVPN**.
7. Нажмите **Быстрое соединение**.

![Поля подключения SFTP в FileZilla и кнопка «Быстрое соединение»](/img/sftp/sftp6_ru.png)

Если папка сервера появилась в области **Удалённый сайт**, подключение прошло успешно и файловым хранилищем можно пользоваться через FileZilla.

[FileZilla]: https://filezilla-project.org/
