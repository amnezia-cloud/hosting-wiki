# Прокси-сервер SOCKS5

## Общая информация

SOCKS5 — это интернет-протокол, который может обрабатывать любой трафик, используемый для передачи пакетов данных от сервера к клиенту через промежуточный прокси-сервер. При его использовании трафик проходит через прокси-сервер, который использует собственный IP-адрес для окончательного подключения к нужному адресату.

## Установка SOCKS5

1. На главном экране нажмите на название сервера.
2. Нажмите на иконку настроек рядом с названием сервера.
3. Перейдите на вкладку **Сервисы** и выберите **Прокси-сервер SOCKS5**.
4. Оставьте порт по умолчанию или укажите другой, затем нажмите **Установить**.

![Установка прокси-сервера SOCKS5: выбор сервера, вкладки «Сервисы» и порта](/img/socks5-proxy-server/ru_socks5_proxy_server1.png)

## Просмотр настроек SOCKS5

1. После установки снова перейдите на вкладку **Сервисы** и выберите **Прокси-сервер SOCKS5**.
2. Выберите **Прокси-сервер SOCKS5 настройки сервера**. Откроется экран **Настройки SOCKS5**.

На экране настроек будут показаны хост, порт, имя пользователя и пароль.
