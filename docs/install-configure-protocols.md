# Установка и настройка протоколов

## О протоколах

AmneziaVPN — мультипротокольный self-hosted VPN-клиент. Он поддерживает настройку и установку современных VPN-протоколов с открытым исходным кодом: AmneziaWG, XRay VLESS Reality, OpenVPN и WireGuard.

Более подробное описание протоколов — в [этой] статье. Ниже описано, как установить и настроить VPN-протоколы в AmneziaVPN.

## Как открыть настройки протокола

1. Откройте AmneziaVPN и нажмите на название сервера в нижней части экрана.
2. Нажмите на значок шестерёнки рядом с подключением к серверу.
3. Откройте вкладку **Протоколы** и выберите протокол.

![Переход к вкладке «Протоколы» через настройки сервера](/img/install-configure-protocols/ru_install_configure_protocols.png)

## Настройки XRay VLESS Reality

::: warning Ограничения настройки XRay

В параметрах сервера XRay VLESS Reality можно изменять только **Имя сервера (SNI)** и при необходимости **порт**. Изменение других настроек приведёт к неработоспособности подключения.

Не рекомендуем изменять установленный по умолчанию порт **443**. Меняйте его только в том случае, если этот номер порта уже занят. Выбранный для XRay номер порта должен быть свободен и по TCP, и по UDP. Например, если AmneziaWG уже использует `443/UDP`, установить XRay на порт `443` нельзя.
:::

1. На вкладке **Протоколы** выберите **XRay**.
2. Откройте **XRay настройки сервера**.
3. На экране **Настройки XRay VLESS** откройте **Security**.
4. В поле **Имя сервера (SNI)** рекомендуем указать `www.googletagmanager.com`.
5. Нажмите **Сохранить**, а затем — **Продолжить**.

![Настройка XRay: выбор протокола, изменение SNI, сохранение и подтверждение изменений](/img/install-configure-protocols/ru_install_configure_protocols1.png)

*На скриншоте часть подписей на английском: Server Name (SNI) — «Имя сервера (SNI)», Save — «Сохранить», Continue — «Продолжить».*

## Настройки OpenVPN

Протокол OpenVPN гибок в настройке. В нём можно:
- изменить адрес подсети;
- выбрать сетевой протокол;
- изменить порт;
- выбрать метод шифрования и хэширования;
- включить **TLS авторизация** — эта опция добавляет дополнительную подпись (HMAC) к handshake-пакетам SSL/TLS и выполняет проверку целостности пакетов. Пакеты без подписи не обрабатываются. Это повышает безопасность SSL/TLS и помогает защититься от некоторых видов атак;
- включить опцию **Блокировать DNS-запросы за пределами VPN** — она предотвращает утечку адреса DNS-сервера.

## Настройки AmneziaWG

В настройках AmneziaWG можно изменить **Magic**-заголовки и размеры **Junk**-пакетов.
