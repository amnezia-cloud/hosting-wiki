# Host a WordPress site on Tor

Use **AmneziaVPN** to host a WordPress site on your server and make it available on the Tor network.

1. On the main screen, click the server name, then click **⚙️** next to your server. Open the **Services** tab, select **Website in Tor network**, and click **Install**.

   ![Installing Website in Tor network from the server settings](/img/create-tor-website/create_tor_website1_en.png)

2. Once installation is complete, return to the **Services** tab. Select **Website in Tor network**, then **Website in Tor network server settings**. Copy the **Website address** and open it in [Tor Browser].

   The site may take a few minutes to become available on Tor. Use this onion address as the domain when setting up WordPress.

   ![Opening the Tor website settings and copying the onion address](/img/create-tor-website/create_tor_website2_en.png)

3. In WordPress, select **English (United States)** and click **Continue**. The steps below use the English interface.

   ![Choosing the WordPress interface language during setup](/img/create-tor-website/create_tor_website3.png)

4. Enter your site title, username, password, and email address. Save your password, then click **Install WordPress**.

   ![Entering the site title and administrator account details during WordPress setup](/img/create-tor-website/create_tor_website4_en.png)

5. Once WordPress is installed, click **Log In**.

   ![The WordPress installation success screen and Log In button](/img/create-tor-website/create_tor_website5_en.png)

6. Enter your username or email address and password, then click **Log In**.

   ![The WordPress login form with username or email address and password fields](/img/create-tor-website/create_tor_website6_en.png)

7. The WordPress dashboard opens. You can now customize your site and publish content.

   ![The WordPress dashboard after logging in as an administrator](/img/create-tor-website/create_tor_website7_en.png)

For help building your site, see the [WordPress documentation].

[Tor Browser]: https://www.torproject.org/
[WordPress documentation]: https://wordpress.org/documentation/
