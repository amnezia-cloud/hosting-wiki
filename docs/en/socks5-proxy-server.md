# Set up a SOCKS5 proxy

## Overview

SOCKS5 is a protocol for routing traffic through a proxy server. The proxy connects to the destination on your behalf, using its own IP address.

## Install the proxy

1. On the main screen, click the server name.
2. Click the settings icon next to the server name.
3. Go to the **Services** tab and select **SOCKS5 proxy server**.
4. Keep the default port or choose a different one, then click **Install**.

![Installing a SOCKS5 proxy: select the server, open Services, and choose a port](/img/socks5-proxy-server/en_socks5_proxy_server1.png)

## Find your connection details

1. Once installation is complete, return to the **Services** tab and select **SOCKS5 proxy server**.
2. Select **SOCKS5 proxy server server settings** to open **SOCKS5 settings**.

You'll find the host, port, username, and password on this screen.

![Opening SOCKS5 settings to find the proxy connection details](/img/socks5-proxy-server/en_socks5_proxy_server2.png)
