# How to Change My Plan

At the moment there are **no other plans** — every server ships in a single configuration, so there is nothing to switch between and no such option in the client area.

## What the configuration includes {#config}

| Resource | Amount |
| :--- | :--- |
| **CPU** | 1 dedicated core |
| **Memory** | 1 GB RAM |
| **Storage** | 10 GB SSD |
| **Network** | up to 100 MB/s, unlimited traffic |

That is enough for a VPN serving roughly 10 active devices — see **[One server for multiple devices](/en/multiple-devices)**.

Current specs and prices are always listed on **[amnezia.host](https://amnezia.host)**.

## If you need more resources {#more}

*   **Order a second server** — for another location or another group of users, for example.
*   **Write to support** via **[my.amnezia.host](https://my.amnezia.host)**: describe the load you need and they will outline the available options.

The billing term can be changed separately: **[How to change the billing period](/en/billing-period)**.
