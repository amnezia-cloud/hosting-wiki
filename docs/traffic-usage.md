# Сколько трафика расходует VPN

Сам VPN-сервер трафик не генерирует — расход полностью зависит от вашей активности.

## Правило удвоения {#double}

Каждый гигабайт проходит через сервер дважды: сервер сначала скачивает данные себе, затем отдаёт их вам.

| Ваше действие | Расход на сервере |
| :--- | :--- |
| Скачали файл 1 ГБ | 2 ГБ (1 ГБ приём + 1 ГБ отдача) |
| Посмотрели фильм 5 ГБ | 10 ГБ |
| Переписка, почта, веб-страницы | десятки-сотни МБ в день |

## Как выбрать тариф {#plan}

Наши серверы идут с безлимитным трафиком и каналом до 100 МБ/с, поэтому считать гигабайты не нужно. Актуальные параметры и цены — на **[amnezia.host](https://amnezia.host)**.

## Как посмотреть фактический расход {#monitor}

*   **Панель 3X-UI** — показывает трафик по каждому клиенту отдельно, в разделе **Inbounds**; там же можно задать лимит на пользователя (**Total Flow**).
*   **На сервере** — командой `vnstat` (устанавливается через `apt install vnstat`) или в разделе статистики личного кабинета.
