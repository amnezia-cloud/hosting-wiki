# Установка AmneziaVPN на iOS для жителей России

Приложение AmneziaVPN скрыто из российского App Store по требованию Роскомнадзора, поэтому скачать его на iPhone или iPad напрямую не получится. В китайском App Store приложение тоже скрыто. Ниже — рабочие варианты, от самого простого к более длинному.

::: tip Возможно, вам ничего из этого не нужно
Если в вашем App Store уже выбран регион, отличный от российского и китайского, приложение просто скачивается из магазина — инструкции ниже можно не читать.
:::

## Сначала попробуйте простое {#quick-options}

### Обновить уже установленное приложение {#reinstall-trick}

Если AmneziaVPN на устройстве есть, его можно обновить даже когда в магазине он не отображается:

**Настройки iPhone** → **Основные** → **Хранилище iPhone** → выберите **AmneziaVPN** → **Сгрузить приложение** → **Переустановить**.

### Использовать DefaultVPN {#defaultvpn}

Если приложения на устройстве нет, для подключения к **Amnezia Free** и **Amnezia Premium** мы рекомендуем наше альтернативное приложение **DefaultVPN** — оно доступно в российском App Store. Подробности по работе с ним есть в документации Amnezia, в разделе об особенностях использования сервисов Amnezia на iOS в России.

### Подключиться к своему серверу другим клиентом {#other-clients}

Для **своего VPS** приложение Amnezia не обязательно: ключи, выданные через панель 3X-UI, работают в любом клиенте с поддержкой VLESS — на iOS это Streisand, FoXray, Shadowrocket, V2Box. Как выдать такой ключ — **[Панель 3X-UI](/3x-ui#client-key)**.

## Почему приложения нет в магазине {#why-hidden}

*   AmneziaVPN **скрыт** из российского и китайского App Store — это ограничение магазина, а не поломка устройства или аккаунта.
*   Помогает аккаунт Apple с другим регионом: можно **сменить регион** у текущего аккаунта или **создать новый**.
*   Регион в App Store и регион в системных настройках iOS (**Основные → Язык и регион**) — **разные параметры**. Менять язык системы не требуется.

::: tip Новый аккаунт обычно проще смены региона
Для смены региона нужно отключить семейный доступ, обнулить баланс внутреннего счёта и отменить все подписки. Для нового аккаунта достаточно свободного адреса электронной почты — поэтому в большинстве случаев этот путь короче.
:::

## Вариант 1. Новый аккаунт Apple {#new-account}

Ниже — процесс создания аккаунта в регионе США с подтверждением по российскому номеру телефона. Регионы выбраны для примера: можно указать любые другие.

### Шаг 1. Создайте аккаунт

Откройте страницу **[account.apple.com/account](https://account.apple.com/account)** и заполните данные:

| Поле | Что указать |
| :--- | :--- |
| **Имя и фамилия** | любые ваши данные |
| **Страна/регион учётной записи** | например, Соединённые Штаты Америки |
| **Дата рождения** | ваша |
| **Адрес электронной почты** | действительный и **не привязанный** к существующему аккаунту Apple — на него придёт код |
| **Пароль** | понадобится для входа: запомните или сохраните в менеджере паролей |
| **Страна телефонного номера** | +7 (Россия) |
| **Номер телефона** | действительный, можно от другого аккаунта Apple — на него придёт SMS с кодом |
| **Вариант подтверждения** | «Текстовое сообщение» |
| **Рассылки** | галочки на анонсы и новости — на ваше усмотрение |
| **Проверочный код** | с изображения |

Нажмите **Продолжить**, введите код из письма, затем код из SMS. Если всё верно, аккаунт создан и им можно сразу пользоваться.

::: warning Ошибка на шаге ввода кода из SMS
Это распространённая ошибка Apple, не связанная с выбранным регионом: она возникает даже при регистрации российского аккаунта с новым российским номером. Повторите попытку позже или обратитесь на горячую линию Apple в России.
:::

### Шаг 2. Войдите под новой учётной записью

1.  Откройте **Настройки** и нажмите на своё имя.
2.  Выберите **«Контент и покупки»** → **«Выйти»**. Это касается только App Store — на устройстве вы останетесь авторизованы под своим Apple ID.
3.  Снова нажмите **«Контент и покупки»** и выберите пункт **«Не Имя Фамилия»** — то есть вход под другим логином.
4.  Введите логин и пароль нового аккаунта.

При первой загрузке приложения Apple попросит принять положения и условия, выбрать адрес выставления счёта и способ оплаты. Если покупки не планируются, выбирайте вариант **«Нет»**.

### Шаг 3. Скачайте AmneziaVPN

Приложение появится в поиске App Store нового региона.

::: danger Сначала удалите старую версию
Перед установкой убедитесь, что ранее установленная версия AmneziaVPN удалена, — иначе установка завершится ошибкой.
:::

## Вариант 2. Смена региона текущего аккаунта {#change-region}

Пример: смена региона российского аккаунта на США с подтверждением по российскому номеру.

### Шаг 1. Обнулите баланс внутреннего счёта

Откройте App Store и нажмите на аватарку справа вверху. Баланс, если он есть, показан чуть ниже адреса электронной почты. Нет строки с балансом — остатка нет, переходите дальше.

Со ненулевым остатком регион сменить не получится. Если остаток меньше стоимости самого дешёвого приложения и потратить его невозможно, Apple советует обратиться в их поддержку.

### Шаг 2. Отмените платные подписки

**Настройки** → ваше имя → **«Подписки»** → **«Отменить подписку»**.

Кнопки «Отменить подписку» нет или красным показан срок истечения — подписка уже отменена, переходите дальше.

### Шаг 3. Смените регион

1.  **Настройки** → ваше имя → **«Контент и покупки»** → **«Просмотреть»** (возможно, потребуется ввести пароль Apple ID).
2.  Нажмите **«Страна/регион»**. При активных подписках Apple напомнит, что их нужно отменить.
3.  **«Изменить страну или регион»** → выберите страну, например США. Учтите, что часть сервисов Apple в отдельных регионах не работает.
4.  Пролистайте положения и условия → **«Принять»** в правом верхнем углу.
5.  Выберите способ оплаты. Если покупки не планируются — **«Нет»**. Если варианта «Нет» нет, потребуется карта банка **той же страны**, что и выбранный регион: карту грузинского банка к региону США привязать не получится.
6.  Введите адрес и номер телефона для выставления счёта → **«Далее»**. Если этих данных нет, подойдут любые из генератора адресов — Apple их не подтверждает.

Регион изменится; возможно, потребуется заново войти в App Store и другие сервисы. Вернуть российский регион можно в любой момент — например, когда нужные приложения уже установлены.

### Шаг 4. Скачайте AmneziaVPN

::: danger Сначала удалите старую версию
Как и в первом варианте: старую версию нужно удалить до установки, иначе будет ошибка.
:::
