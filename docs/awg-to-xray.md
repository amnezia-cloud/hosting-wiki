# Перестал работать AmneziaWG — переходите на XRay

Если AWG перестал подключаться или соединение «висит» — скорее всего провайдер начал блокировать этот тип трафика. AWG работает поверх **UDP**, и в сетях с жёсткой фильтрацией такой трафик режется целиком. Решение — перевести сервер на **XRay**, который идёт поверх TCP и маскируется под обычный HTTPS.

## Симптомы {#symptoms}

*   Подключение бесконечно «крутится» и обрывается по таймауту.
*   AWG работал раньше и перестал без изменений в настройках.
*   На другой сети (другой оператор, проводной интернет) тот же AWG подключается.

Если сервер не отвечает даже по SSH — дело не в протоколе, начните с **[пошаговой диагностики](/vpn-troubleshooting#error-305)**.

## Решение по шагам {#fix}

1.  **Обновите приложение.** Скачайте последнюю версию клиента AmneziaVPN с GitHub — обязательный шаг, в старых версиях XRay работает некорректно.
2.  **Удалите старый протокол.** В настройках сервера внутри приложения полностью удалите AWG.
3.  **Установите XRay.** Нажмите **«Добавить протокол»** → **XRay** и строго укажите параметры маскировки:

| Параметр | Значение |
| :--- | :--- |
| **Порт** | `443` |
| **SNI** | `ya.ru` |

4.  Дождитесь установки (до минуты) и подключитесь, выбрав XRay в списке протоколов.

## Если с 443 и ya.ru не заработало {#fallback}

Перебирайте по одному изменению за раз:

| Что менять | Варианты | Когда пробовать |
| :--- | :--- | :--- |
| **Порт** | `8443`, затем `80` | 443 занят на сервере или режется провайдером |
| **SNI** | `2gis.ru`, `pochta.ru` | маскировка под `ya.ru` не проходит DPI |
| **Сеть** | другой оператор, проводной интернет | чтобы понять, в чьей сети фильтрация |

Ручная настройка с полным контролем над портами, ключами и доменом маскировки — через веб-панель: **[Панель 3X-UI](/3x-ui)**, раздел **[альтернативных портов](/3x-ui#inbound)**.

## Почему XRay устойчивее {#why}

| | AmneziaWG | XRay / VLESS + Reality |
| :--- | :--- | :--- |
| Транспорт | UDP | TCP + TLS |
| Как выглядит для провайдера | обфусцированный VPN-трафик | обычное HTTPS-соединение с разрешённым сайтом |
| Нагрузка на устройство | ниже | чуть выше на слабых устройствах |
| Устойчивость к DPI | высокая | максимальная |

Сравнение протоколов целиком — **[Протоколы](/protocols)**. Оптимально держать на сервере оба: AWG для скорости, XRay как запасной.
