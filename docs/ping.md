# Не проходит ping до сервера

`Превышен интервал ожидания для запроса` или `100% packet loss` в ответ на `ping` — это **нормально и не означает, что сервер недоступен**.

## Почему ping не отвечает {#why}

ICMP-трафик на наших серверах заблокирован намеренно: так сервер не отвечает на массовое сканирование сети и меньше привлекает внимание автоматических сканеров. Проверять доступность через `ping` в этом случае бессмысленно — ответа не будет даже на полностью рабочем сервере.

## Как проверить, что сервер жив {#how-to-check}

```bash
ssh root@IP_ВАШЕГО_СЕРВЕРА
```

Появился запрос пароля — сервер работает и сеть до него проходит. Соединение зависло или сбросилось — переходите к разбору: **[Не подключается VPN](/vpn-troubleshooting#error-305)**.

Дополнительно статус сервера виден в личном кабинете **[my.amnezia.host](https://my.amnezia.host)** — он должен быть **Active (Running)**.
