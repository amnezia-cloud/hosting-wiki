# AmneziaWG (AWG): подробное руководство

**AmneziaWG (AWG)** — это форк популярного протокола **WireGuard**, доработанный командой Amnezia. Он сохраняет всю скорость и лёгкость WireGuard, но добавляет **обфускацию**, которая скрывает характерный «отпечаток» WireGuard от систем глубокого анализа трафика (DPI).

## В чём отличие от обычного WireGuard

Классический WireGuard очень быстрый, но его рукопожатие (handshake) имеет узнаваемую структуру, и DPI легко его определяет и блокирует. AmneziaWG решает это двумя приёмами:

*   **Мусорные пакеты (junk):** в начало сессии добавляются случайные пакеты, чтобы трафик не начинался с предсказуемого хендшейка.
*   **Маскировка заголовков:** типы служебных сообщений WireGuard заменяются на кастомные значения, поэтому пакет перестаёт «выглядеть как WireGuard».

## Быстрая установка (рекомендуется)

Проще всего не настраивать AWG вручную, а развернуть его через официальное приложение **AmneziaVPN** — все параметры обфускации подбираются автоматически:

1. Установите AmneziaVPN и добавьте свой сервер (см. **[Настройка VPN](/vpn-setup)**).
2. На вкладке протоколов нажмите **«Установить»** напротив **AmneziaWG**.
3. Подключитесь. Готово.

## Параметры обфускации

Если вы настраиваете AWG вручную, в секции `[Interface]` появляются дополнительные параметры. **Они должны совпадать на сервере и на клиенте**, иначе соединение не установится.

| Параметр | Назначение |
| :--- | :--- |
| `Jc` | Количество «мусорных» пакетов в начале сессии (обычно 3–10) |
| `Jmin` | Минимальный размер мусорного пакета, байт |
| `Jmax` | Максимальный размер мусорного пакета, байт (`Jmax` > `Jmin`) |
| `S1` | Размер случайных данных в init-пакете |
| `S2` | Размер случайных данных в response-пакете |
| `H1`–`H4` | Кастомные значения заголовков для 4 типов сообщений WireGuard |

::: warning Важно про параметры
Значения `H1`–`H4` должны быть **уникальными** между собой, а весь набор параметров — **одинаковым** на сервере и клиенте. При установке через приложение AmneziaVPN это делается автоматически.
:::

## Пример конфигурации клиента

```ini
[Interface]
PrivateKey = <приватный_ключ_клиента>
Address = 10.8.1.2/32
DNS = 1.1.1.1

# Параметры обфускации AmneziaWG
Jc = 4
Jmin = 40
Jmax = 70
S1 = 50
S2 = 100
H1 = 1500000000
H2 = 1600000000
H3 = 1700000000
H4 = 1800000000

[Peer]
PublicKey = <публичный_ключ_сервера>
PresharedKey = <пресхаред_ключ>
Endpoint = ВАШ_IP:ПОРТ
AllowedIPs = 0.0.0.0/0, ::/0
PersistentKeepalive = 25
```

## Клиентские приложения

*   **AmneziaVPN** — Windows, macOS, Linux, Android, iOS (рекомендуется).
*   **AmneziaWG** — отдельное приложение для импорта готового конфига.

## Когда выбирать AWG

*   <Icon name="check" tone="ok" /> Повседневное использование, стриминг, игры — там, где важна максимальная скорость и минимальный пинг.
*   <Icon name="check" tone="ok" /> Мобильный интернет — быстрое переподключение и низкий расход батареи.
*   <Icon name="warning" tone="warn" /> Если провайдер полностью блокирует **UDP** — AWG может не подключиться. В этом случае используйте **[VLESS + Reality](/vless)**, работающий поверх TCP.

::: tip Совет
Установите на сервер оба протокола — **AmneziaWG** как основной, а **VLESS** как запасной. Если AWG перестал подключаться, переключитесь на VLESS в один клик.
:::
