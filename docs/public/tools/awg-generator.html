Генератор параметров AmneziaWG 3.1

Уникальные параметры обфускации для сервера в AmneziaVPN. Ниже — три экрана «Настройки AmneziaWG» как в приложении: поля в том же порядке и с теми же названиями. Нажмите на поле — значение скопируется.

🔒 Всё считается в браузере — ничего не отправляетсяAmneziaWG 3.1 · AmneziaVPN
🧭С чего начать?Настройка сервера в приложении AmneziaVPN⌄
  1. Установите протокол AmneziaWG 3.1: в приложении AmneziaVPN нажмите шестерёнку ⚙️ у сервера → вкладка «Протоколы» → AmneziaWG → установить.
  2. Откройте «Настройки сервера» → «AmneziaWG» → «AmneziaWG настройки сервера».
  3. Нажмите «Сгенерировать» ниже и перенесите значения в поля с теми же названиями — экран за экраном, сверху вниз.
  4. Нажмите «Сохранить» → «Продолжить» и дождитесь переустановки протокола. Подключения выдайте заново.

Уже есть файл конфига? Выберите вторую карточку ниже.

🧭С чего начать?Как получить конфиг из приложения⌄
  1. Установите протокол AmneziaWG на сервер в AmneziaVPN, если он ещё не стоит: шестерёнка ⚙️ у сервера → «Протоколы» → AmneziaWG.
  2. Нажмите «Поделиться» на нижней панели (слева от шестерёнки) и откройте вкладку «Соединение».
  3. Выберите сервер, протокол AmneziaWG и формат подключения «Оригинальный формат AmneziaWG». Нажмите «Поделиться» → «Копировать» (сохранять файл не обязательно).
  4. Вставьте скопированный текст в левое окно ниже — новый конфиг соберётся справа.

QR-код для оригинального формата не подходит — используйте «Копировать».

Куда вставлять — пошагово
  1. AmneziaVPN → Настройки сервера → AmneziaWG → AmneziaWG настройки сервера.
  2. Перенесите значения в поля с теми же названиями — экран за экраном, сверху вниз.
  3. Поставьте галочку HeaderProtectionKey, если шифрование заголовков включено. Сам ключ создаст приложение.
  4. Поля I1–I5 оставьте пустыми, если не включали цепочку CPS. Галочки RandomTrailers и DisableCookies оставьте включёнными.
  5. В настройках подключения выставьте MTU = 1280.
  6. Нажмите Сохранить → Продолжить и дождитесь переустановки протокола.
