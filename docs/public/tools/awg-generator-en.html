🧭Where to start?Setting up the server in the AmneziaVPN app⌄
  1. Install the AmneziaWG 3.1 protocol: in AmneziaVPN 5.0.1.5 tap the gear ⚙️ by your server → Protocols tab → AmneziaWG → install. Already on 2.0? See “AmneziaWG: 2.0 → 3.1”.
  2. Open Server settings → AmneziaWG → AmneziaWG server settings.
  3. Press “Generate” below and copy the values into the fields with the same names — screen by screen, top to bottom.
  4. Press Save → Continue and wait for the protocol to reinstall. Re-issue connections afterwards.

Already have a config file? Pick the second card below.

🧭Where to start?How to get a config file from the app⌄
  1. Install the AmneziaWG protocol on your server in AmneziaVPN if it isn’t installed yet: gear ⚙️ by the server → Protocols → AmneziaWG.
  2. Click Share in the bottom bar (left of the gear) and open the Connection tab.
  3. Choose your server, the AmneziaWG protocol and the connection format AmneziaWG native format. Click Share and save the .conf file.
  4. Open the file in a text editor, copy all the text and paste it into the left window below — the new config appears on the right.

QR codes don’t work with this format — you need the .conf file itself.

  1. AmneziaVPN → Server settings → AmneziaWG → AmneziaWG server settings.
  2. Copy the values into the fields with the same names — screen by screen, top to bottom.
  3. Tick HeaderProtectionKey if header encryption is on. The app creates the key itself.

  5. In the connection settings, set MTU = 1280.
