# Как запустить свой <span class="green">VPN</span>

Три простых шага для создания своего собственного VPN на виртуальном сервере.

::: info Важно
Если вы получили готовый ключ через сервисы *Amnezia Free* или *Amnezia Premium*, покупать собственный сервер не нужно. Просто откройте полученный файл конфигурации с помощью официального приложения Amnezia.
:::

## Шаг 1. Покупка виртуального сервера (VPS)

Если у вас еще нет своего сервера, вам необходимо его приобрести. При выборе хостинга ориентируйтесь на следующие критерии:

*   **Операционная система:** Linux (рекомендуется Ubuntu 22.04 или Debian 12).
*   **Архитектура процессора:** x86-64.
*   **Виртуализация:** Строго **KVM**.
*   **Сеть:** Обязательна поддержка адреса IPv4.
*   **Оперативная память (RAM):** Не менее 1 Гб (рекомендуется 2 Гб).
*   **ПО:** Предустановленное программное обеспечение и панели управления не требуются.

::: danger Внимание: несовместимые хостинги
Серверы компаний **Reg.ru** и **Yandex Cloud** технически не подходят для автоматической установки VPN через приложение Amnezia!
:::

::: warning Обратите внимание
Сторонние хостинги используются исключительно в качестве примера. Мы не несем ответственности за качество оказываемых ими услуг и потенциальные технические риски. Большинство зарубежных VPS-провайдеров сейчас поддерживают оплату российскими банковскими картами и криптовалютой.
:::

## Шаг 2. Получение данных для доступа

После успешного заказа и активации сервера на электронную почту, указанную при регистрации у хостинг-провайдера, придет информационное письмо.

**Для настройки нам понадобятся три параметра из этого письма:**

1.  **IP-адрес** сервера
2.  **Имя пользователя** (User name / User ID, обычно `root`)
3.  **Пароль** (Password)

::: warning Что делать, если письмо не пришло?
Некоторые провайдеры в целях безопасности не отправляют пароли по почте. В таком случае все реквизиты доступа можно найти внутри вашего личного кабинета на сайте хостинга. Если у вас возникнут трудности с поиском данных, обратитесь в их службу технической поддержки.
:::

## Шаг 3. Установка и запуск через AmneziaVPN

1.  Скачайте и установите официальное приложение **AmneziaVPN** для вашей операционной системы (Windows, macOS, Linux, iOS или Android).
2.  Запустите приложение на вашем устройстве.
3.  Нажмите кнопку **«У меня есть данные для подключения»**.
4.  В появившемся меню выберите пункт **«Настроить свой сервер»**.
5.  Введите скопированные ранее данные вашего сервера: IP, логин и пароль.
6.  Нажмите кнопку **«Продолжить»** и следуйте автоматическим интерактивным подсказкам приложения.
