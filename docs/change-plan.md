# Как изменить свой тариф

На данный момент **других тарифов нет** — все серверы выдаются в единой конфигурации, поэтому переключать тариф не требуется и такой опции в личном кабинете нет.

## Что входит в конфигурацию {#config}

| Ресурс | Объём |
| :--- | :--- |
| **Процессор** | 1 выделенное ядро CPU |
| **Оперативная память** | 1 ГБ RAM |
| **Накопитель** | 10 ГБ SSD |
| **Сеть** | канал до 100 МБ/с, безлимитный трафик |

Этого достаточно для VPN примерно на 10 активных устройств — см. **[Один сервер для нескольких устройств](/multiple-devices)**.

Актуальные параметры и цены всегда указаны на **[amnezia.host](https://amnezia.host)**.

## Если нужно больше ресурсов {#more}

*   **Закажите второй сервер** — например, для другой локации или другой группы пользователей.
*   **Напишите в поддержку** через **[my.amnezia.host](https://my.amnezia.host)**: расскажите, какая нагрузка нужна, и вам подскажут доступные варианты.

Сменить срок оплаты можно отдельно: **[Как сменить период оплаты](/billing-period)**.
