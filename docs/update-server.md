# Как обновить сервер

## Общая информация

Инструкция по обновлению сервера предназначена для пользователей **Amnezia Self-hosted** с Ubuntu или Debian, которые используют **приложение AmneziaVPN**.

:::warning
Во время этих действий сервер будет недоступен для всех пользователей. Подключение через Xray перестанет работать у всех пользователей этого сервера после выполнения действий из этой инструкции. Владельцу потребуется заново поделиться доступом.
:::

## Подключитесь к серверу по SSH

Откройте терминал на компьютере и выполните команду, заменив `IP_СЕРВЕРА` на IP-адрес вашего VPS:

```bash
ssh root@IP_СЕРВЕРА
```

Воспользуйтесь подробной инструкцией [как подключиться по SSH](/server-management#ssh), если у вас возникнут любые вопросы на этом этапе.

## Шаг 1. Отключите MPTCP

Отключение MPTCP снижает риск атаки.

Выполните команды по очереди:

```bash
sudo sysctl -w net.mptcp.enabled=0
```

```bash
echo 'net.mptcp.enabled=0' | sudo tee /etc/sysctl.d/99-disable-mptcp.conf
```

Первая команда отключает создание новых MPTCP-сокетов на сервере, вторая сохраняет настройку для следующих загрузок.

## Шаг 2. Удалите старый Xray

Настройка MPTCP на сервере может не распространяться на контейнер Xray. Поэтому перед обновлением системы удалите старый Xray через приложение:

1. Откройте **AmneziaVPN**, в котором есть подключение к серверу с **полным доступом**.
2. Нажмите на иконку ⚙️ (**шестерёнка**) → **Серверы** → выберите ваш сервер.
3. Откройте вкладку **Протоколы** → **Xray** → **Удалить** и подтвердите удаление.

## Шаг 3. Обновите систему и перезагрузите сервер

Обновления системы и ядра Linux содержат исправления ошибок и уязвимостей.

Вернитесь в терминал и запустите обновление:

```bash
sudo apt update && sudo apt dist-upgrade -y
```

Дождитесь успешного завершения установки, затем **обязательно перезагрузите сервер**:

```bash
sudo reboot
```

После перезагрузки сервера SSH-соединение прервётся. Дождитесь запуска сервера.

:::info
Обновления устанавливаются из подключённых репозиториев. Доступность исправлений зависит от версии системы и используемых репозиториев. Успешное обновление само по себе не подтверждает устранение всех уязвимостей.
:::

## Шаг 4. Установите обновлённый Xray

Если вы ещё не обновили **AmneziaVPN**, обновите приложение до [последней версии на GitHub](https://github.com/amnezia-vpn/amnezia-client/releases/latest) с **Xray 26.10.31 или новее**. Затем заново установите протокол **Xray** на сервер по инструкции ниже.

1. Откройте обновлённое приложение **AmneziaVPN**.
2. Откройте **Настройки** → **Серверы** → выберите ваш сервер → **Протоколы**.
3. Выберите **Xray**, нажмите **Установить** и дождитесь завершения установки.
4. Подключитесь к VPN и заново поделитесь доступом с другими пользователями сервера.
