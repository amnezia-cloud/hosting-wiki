# Как обновить сервер из-за уязвимости CVE-2026-98432

Источник: [Amnezia Docs](https://docs.amnezia.org/ru/documentation/instructions/update-server-cve-2026-98432/).

## Шаг 1. Удалите старый Xray

:::warning
Во время перезагрузки сервер будет недоступен для всех пользователей. При выполнении шагов 1–3 ниже подключения через Xray перестанут работать у всех пользователей этого сервера. Владельцу потребуется заново поделиться доступом.
:::

Перед обновлением системы удалите старый Xray через приложение:

1. Откройте **AmneziaVPN**, в котором есть подключение к серверу с **полным доступом**.
2. Нажмите на иконку ⚙️ (**шестерёнка**) → **Серверы** → выберите ваш сервер.
3. Откройте вкладку **Протоколы** → **Xray** → **Удалить** и подтвердите удаление.

## Шаг 2. Обновите систему и перезагрузите сервер

Для устранения самой уязвимости требуется ядро Linux с исправлением.

Обновить систему и перезагрузить сервер можно через приложение **AmneziaVPN**:

:::info
Опция **Обновить пакеты на сервере** появилась в **AmneziaVPN 5.1.0.6**. Если у вас более ранняя версия приложения, обновите его до [последней версии на GitHub](https://github.com/amnezia-vpn/amnezia-client/releases/latest) или на [странице загрузок](https://amnezia.org/downloads) ([зеркало](https://storage.googleapis.com/amnezia/amnezia.org?m-path=/downloads)).
:::

1. На главном экране нажмите на название сервера, затем на иконку ⚙️ (**шестерёнка**) рядом с нужным сервером.
2. Откройте вкладку **Управление** → **Обновить пакеты на сервере**.

    Функция обновляет системные пакеты — аналогично выполнению `sudo apt update && sudo apt dist-upgrade -y` в Ubuntu.

3. Нажмите **Продолжить** и дождитесь сообщения об успешном обновлении пакетов.
4. После успешного обновления возникнет окно с предложением перезагрузки сервера. Нажмите **Перезагрузить** и дождитесь запуска сервера. **Перезагрузка обязательна**, чтобы сервер начал использовать обновлённое ядро.

![Обновление пакетов и перезагрузка сервера в AmneziaVPN](/img/update-server/Update_server_packages_ru_1.png)

:::info
Кнопка **Обновить пакеты на сервере** устанавливает обновления из подключённых репозиториев, но не гарантирует получение ядра с исправлением этой уязвимости.

В **Ubuntu** для некоторых версий системы исправление пока доступно только в тестовом репозитории `-proposed` и обычным обновлением не устанавливается. Подробнее — в [информации Canonical](https://ubuntu.com/blog/fixes-available-in-proposed-pocket-for-cve-2026-98432).

Если вы используете другой дистрибутив, проверьте в его официальных уведомлениях о безопасности, выпущено ли исправление **CVE-2026-98432** для вашей версии системы и как его установить.
:::

## Шаг 3. Установите обновлённый Xray

Для установки обновлённого **Xray** требуется **AmneziaVPN 5.1.0.6 или новее**. Если у вас более ранняя версия приложения, обновите его до [последней версии на GitHub](https://github.com/amnezia-vpn/amnezia-client/releases/latest) или на [странице загрузок](https://amnezia.org/downloads) ([зеркало](https://storage.googleapis.com/amnezia/amnezia.org?m-path=/downloads)). Затем заново установите протокол **Xray** на сервер по инструкции ниже.

1. Откройте обновлённое приложение **AmneziaVPN**.
2. Откройте **Настройки** → **Серверы** → выберите ваш сервер → **Протоколы**.
3. Выберите **Xray**, нажмите **Установить** и дождитесь завершения установки.
4. Подключитесь к VPN и заново поделитесь доступом с другими пользователями сервера.

:::warning
Если после выполнения этой инструкции вы снова перезагрузите сервер, потребуется переустановить контейнер **Xray**, повторив шаги 1 и 3. После каждой такой перезагрузки сервер вновь становится уязвимым для **CVE-2026-98432** до переустановки контейнера. Это поведение будет исправлено в будущих версиях **AmneziaVPN**.
:::
