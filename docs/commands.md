# Быстрый старт <span class="green">по работе с VPS</span>

Это руководство поможет вам выполнить первое подключение к вашему новому серверу Amnezia Hosting и познакомит с базовыми командами для управления системой.

## Шаг 1. Получение данных сервера

После успешной активации VPS в личном кабинете, на вашу электронную почту придут основные реквизиты доступа:

*   **IP-адрес сервера** (например, `192.168.1.100`)
*   **Имя пользователя** (обычно `root`)
*   **Пароль** или **SSH-ключ**

## Шаг 2. Подключение к серверу по SSH

В зависимости от вашей операционной системы, откройте терминал и введите команду для подключения.

**Для Linux / macOS / Windows (через Терминал или PowerShell):**

```bash
ssh root@IP_АДРЕС_ВАШЕГО_СЕРВЕРА
```

*Пример:* `ssh root@192.168.1.100`

::: info Первое подключение
При первом подключении терминал выдаст предупреждение `The authenticity of host... can't be established`. Введите **`yes`** и нажмите **Enter**, после чего вставьте ваш пароль от сервера (символы пароля при вводе отображаться не будут).
:::

## Шаг 3. Первоочередное обновление системы

Сразу после первого входа на сервер обязательно обновите список пакетов и установленные программы до актуальных версий безопасности. Выполните команду:

```bash
apt update && apt upgrade -y
```

## Основные команды для управления VPS

Вот базовый набор команд Linux, который необходим каждому администратору:

| Команда | Описание |
| :--- | :--- |
| `pwd` | Показать текущую папку, в которой вы находитесь |
| `ls -la` | Показать список всех файлов и папок в текущей директории |
| `cd /путь/к/папке` | Перейти в другую папку |
| `df -h` | Показать, сколько свободного места на диске |
| `free -h` | Показать использование оперативной памяти |
| `htop` | Запустить диспетчер задач (мониторинг процессора и ОЗУ) |
| `nano файл` | Открыть текстовый файл в редакторе (выход — `Ctrl + X`) |
| `apt install пакет` | Установить программу из репозитория |
| `systemctl status служба` | Проверить статус службы (например, `ssh`) |
| `reboot` | Перезагрузить ваш сервер |
