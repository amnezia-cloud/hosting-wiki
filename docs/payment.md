# Как оплатить хостинг

Оплата проходит в личном кабинете **[my.amnezia.host](https://my.amnezia.host)** — раздел «Счета». Доступны три платёжных сервиса, выбирайте по удобному способу оплаты.

| Сервис | Способы оплаты |
| :--- | :--- |
| **FreeKassa** | российские банковские карты, СБП |
| **ЮKassa** | счёт YooMoney, оплата наличными |
| **Stripe** | иностранные банковские карты |

## Порядок оплаты {#how}

1.  Войдите в личный кабинет **[my.amnezia.host](https://my.amnezia.host)**.
2.  Откройте раздел «Счета» и выберите неоплаченный счёт — либо нажмите **Renew Service** в карточке сервера.
3.  Выберите платёжный сервис и завершите оплату.
4.  Услуга продлевается автоматически после подтверждения платежа.

## Счета и история {#invoices}

Все выставленные счета и история платежей хранятся в личном кабинете в разделе «Счета» — оттуда же скачиваются документы по оплате.

## Цены и периоды {#prices}

Актуальные тарифы, доступные периоды оплаты и цены — на **[amnezia.host](https://amnezia.host)**. Сменить период оплаты можно через поддержку: **[Как сменить период оплаты](/billing-period)**.

::: tip Оплата не прошла
Попробуйте другой платёжный сервис из таблицы — часто отказ приходит со стороны банка, а не хостинга. Если ни один способ не срабатывает, создайте тикет: **[Обращение в поддержку](/support)**.
:::
