# Реклама на YouTube через VPN

Показывать рекламу или нет — решает сам YouTube, по IP-адресу и совокупности признаков аккаунта. Ни VPN, ни хостинг на это решение не влияют, поэтому в одних локациях реклама пропадает, а в других остаётся.

::: warning Гарантий здесь нет
Правила YouTube меняются без предупреждения: локация, где реклама не показывалась месяц назад, может начать её показывать. Ниже — то, что известно на практике, а не обещание.
:::

## Где нет рекламной программы YouTube {#no-program}

В этих странах местный рекламный рынок не запущен или платформой не монетизируется, поэтому при подключении через их IP-адреса реклама в видео обычно пропадает:

## Что можно сделать на своей стороне {#workarounds}

Если через вашу локацию реклама показывается, помогают клиентские способы:

| Платформа | Вариант |
| :--- | :--- |
| **Браузеры** | расширение **uBlock Origin** |
| **Браузеры** | альтернативная ссылка вида `https://yout-ube.com/watch?v=ID` — например, `https://youtube.com/watch?v=SdxteCtjXJ8` → `https://yout-ube.com/watch?v=SdxteCtjXJ8` |
| **Android TV** | приложение **SmartTube** |
| **Android-смартфоны** | проект **YouTube ReVanced** |

Самый предсказуемый вариант без всяких оговорок — подписка **YouTube Premium**: она убирает рекламу независимо от локации и IP-адреса.

::: tip Локация сервера — не то же самое, что страна в базах
Иногда сервис определяет страну сервера иначе, чем указано в заказе: базы GeoIP обновляются с задержкой. Разбор — **[Почему не совпадает геолокация сервера](/geolocation)**.
:::
